📊 HANA Data Manager

Query, export, and upload EA/IC tracking data from HANA Cloud to SharePoint Archive.
How to use HANA Data Manager
Purpose: Query EA (Expense Audit) and IC (Invoice Capture) tracking records stored in HANA Cloud, and export or archive them to SharePoint.
Steps
  1. Select a date — this is a daily query (one date at a time).
  2. Check EA / IC — include one or both tracker types.
  3. Click Preview Count to verify how many records exist before acting.
  4. Click Export to CSV to download a raw data file.
  5. Click Upload to SP Archive to push the data to the SharePoint Archive folder. Do this after verifying the count.
Buttons
Preview CountShows how many EA/IC rows exist for the selected date. Use this before exporting or uploading.
Export to CSVDownloads all matching records as a .csv file. Useful for manual review or reconciliation.
Upload to SP ArchiveSends data to the SharePoint Archive folder. Requires a successful Preview Count first.
Backfill PseudocodesUpdates records missing a PSEUDOCODE by matching their auditor email against the Manpower roster. Run this if pseudocodes appear blank in reports.
⚠️ Upload to SP Archive is a one-way action. Always run Preview Count first to confirm the correct records will be sent.

✏️ HANA Editor

Directly edit EA/IC tracking records in HANA.
How to use HANA Editor
Purpose: Search, edit, add, and delete individual EA (Expense Audit / IA) and IC (Invoice Capture) tracking records directly in HANA. Use this to correct errors that auditors cannot fix from the Activity Tracker.
Steps
  1. Select the table: IA — EA (Expense Audit) or IC (Invoice Capture).
  2. Set a date range and optionally enter an auditor email to narrow results.
  3. Click Search to load records.
  4. Use Edit Row to modify a single record inline, or Edit in Grid for bulk field editing.
  5. Use Add Row to insert a new record manually.
  6. Check rows and use Delete Selected to remove records permanently.
Key Fields — EA (Expense Audit)
REPORTIDUnique report identifier from the audit system.
ENTITYCODEClient/entity code being audited.
AUDITOREMAILSAP email of the auditor who processed the report.
STARTTIME / ENDTIMETimestamp when the auditor started and finished. Used to compute duration and utilization.
WORKINGONTask type code (e.g. IA, IC).
PSEUDOCODEAnonymized auditor identifier. Used in reports instead of real names.
QUESTIONCOUNTNumber of audit questions in the report.
CMC / JFFSpecial audit flags (Case Management / Just For Fun review).
Key Fields — IC (Invoice Capture)
BATCHIDUnique batch identifier for the invoice capture job.
CLIENTNAMEName of the client whose invoices were processed.
INVOICECOUNTNumber of invoices in the batch.
⚠️ Deleting records is permanent and cannot be undone. Always double-check before using Delete Selected. When in doubt, edit the record instead of deleting it.
Search to load records.

HANA Manpower Manager

Upload monthly files, manage the roster, and compare changes over time.
How to use HANA Manpower Manager
Purpose: Upload and maintain the monthly Global Audit Manpower File in HANA. Replaces the manual SP Excel process. All portal pseudocode lookups, TL team builds, and supervisor checks now draw from this table.
📤 Upload tab
  1. Select the Month (e.g. August 2026).
  2. Choose the consolidated Global Audit Manpower File Excel.
  3. Click Upload.
Only the ManpowerFile sheet is read. Uploading for an existing month replaces all data for that month. A diff vs. the previous month is shown automatically.
📋 Roster tab
  • Select a month to load the full roster.
  • Use the search bar to filter by name, email, team lead, or function.
  • Click Save on any row to update individual fields.
  • Check rows and click Delete Selected to remove entries.
  • Click Export CSV to download the roster.
🔀 History / Diff tab
  • Select a From month and a To month.
  • Click Compare to see what changed.
■ Green = new hires / added entries
■ Red = separated / removed entries
■ Yellow = changed fields (shows old → new value)
Field Reference
EMPID / EMPID_TFSAP Employee ID and TF-system Employee ID.
PSEUDONAMEAnonymized code shown in reports (e.g. "Auditor 0123", "Support 0456"). This is what appears in all portal dashboards.
EMAILAuditor's SAP email. This is the primary key used to match records across the portal.
FULLNAMEFull legal name in "Last, First" format (e.g. "Dela Cruz, Juan").
TEAMLEADFull name of the auditor's direct team lead. Used by the portal to build TL dashboards.
CLUSTERMANAGERCluster Manager overseeing the team lead.
SENIORMANAGERSenior Manager above the cluster manager.
HIREDATE / LWDDate of hire and Last Working Day (blank if still active).
STATUSEmployment status — typically "Active" or "Separated".
FUNCFunction / queue (e.g. CSS, USD, SME, AS 1, CSR 1).
GRPGroup within the function (e.g. RND, QUA, Internship).
LOCATIONWork location / site code.
SUPCODEGDPR supervisor code (e.g. "IN1"). Used for data privacy compliance.
SWBNAMEWorkbench/system name associated with the auditor.
OLDPSEUDOCODEPrevious pseudoname if the auditor was renamed (for historical lookup).
CAREERLEVEL / GRADELEVELSAP career and grade level designations.
CSLOBCS Line of Business the auditor belongs to.
Monthly Maintenance Routine
  1. Collect updated rosters from all stakeholders (last week of the month).
  2. Consolidate into the Global Audit Manpower File Excel (ManpowerFile sheet).
  3. Go to Upload tab → select the correct month → upload.
  4. Review the diff — confirm new hires (green) and separated auditors (red) are expected.
  5. If any entry is wrong, go to Roster tab → find the row → edit and save inline. No need to re-upload the whole file.
⚠️ The TEAMLEAD field drives TL dashboard team membership. If an auditor's TEAMLEAD is blank or mistyped, that auditor will not appear in their TL's dashboard. Always verify TEAMLEAD names match exactly.
Upload the consolidated Global Audit Manpower File Excel. Only the ManpowerFile sheet is imported. Existing data for the selected month will be replaced.
